# Lumina Select v0.5 Professional Culling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留 Torch 标准版与 OpenCV 轻量版的前提下，把 v0.4 原型升级为专业、可解释、可撤销且能通过 XMP 无缝交付 Lightroom Classic 的 v0.5 本地选片工具。

**Architecture:** 保留 `engine/` 中的分析流水线和 `InferenceBackend` 扩展点，把数据库迁移、资产配对、复核状态、XMP 与导出拆成不依赖 Qt 的服务层；PyQt6 界面改为“引导式导入/分析 + 专业复核工作台”，使用 Qt Model/View 虚拟化胶片带，所有 RAW 解码、推理、复制和 XMP 写入都在工作线程中执行。发布构建通过依赖锁、许可证门禁和双发行契约保证可复现性。

**Tech Stack:** Python 3.12、PyQt6 6.8.1、pytest 8、pytest-qt、SQLite WAL/`PRAGMA user_version`、OpenCV 4.11、Pillow 11、rawpy、MediaPipe 0.10.21、Torch/torchvision/Transformers（标准版）、lxml、ExifTool（仅处理导出副本中的非 RAW XMP）、PyInstaller 6、Inno Setup 6、pip-tools。

## 3. 关键技术决策

| 关注点 | v0.5 决策 | 原因 |
| --- | --- | --- |
| UI 框架 | 保留 PyQt6，按 widgets/services 拆分 | 降低算法和打包回归；商业发行另受许可门禁约束 |
| 胶片带 | `QAbstractListModel + QListView + delegate` | 1000 项时避免创建 1000 个 QWidget |
| 图片画布 | `QGraphicsView/QGraphicsScene` | 原生支持适配、缩放、平移与区域定位 |
| 并发 | `QThread` 工作对象 + 不可变 DTO + generation token | 防止 UI 卡顿和旧任务回写新项目 |
| 数据库 | SQLite WAL + `PRAGMA user_version` 顺序迁移 | 保留 v0.4 数据并提供可恢复升级 |
| RAW 预览 | 配对 JPEG → RAW 内嵌 JPEG → half-size 显影 | 优先低延迟，不为选片完整显影 RAW |
| RAW 元数据 | lxml 合并 `.xmp` sidecar | 精确保留 Lightroom 命名空间并可原子写入 |
| 非 RAW 元数据 | ExifTool 写入导出副本的 XMP 区段 | Lightroom 对 JPEG/TIFF/PSD/DNG 使用文件内元数据；不重编码像素 |
| 质量评分 | OpenCV 技术分两版共享，Torch 保留 CLIP/ViT | 移除 `pyiqa` 非商业许可且保持双版本差异 |
| 可复现构建 | pip-tools 锁文件 + PyInstaller 契约 + 许可证扫描 | 防止依赖漂移和打包内容失真 |
